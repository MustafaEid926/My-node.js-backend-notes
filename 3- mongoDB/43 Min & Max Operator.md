
## **مقدمة: معاملات التحديث للحقول الرقمية (Numeric Update Operators)**
استكمالاً لدروس تحديث البيانات، يركز هذا الدرس على مجموعة من معاملات التحديث المتقدمة التي تُستخدم **حصرياً مع الحقول الرقمية (Numeric Fields)**. هذه المعاملات تتيح لمهندسي قواعد البيانات تحديث القيم الرقمية بناءً على شروط مقارنة ذكية بدلاً من مجرد تعيين قيمة ثابتة، وتشمل: معامل الحد الأدنى (**`min$`**)، معامل الحد الأقصى (**`max$`**)، ومعامل الضرب (**`mul$`**).

---

## **أولاً: معامل الحد الأدنى (`min Operator$`)**

### **المفهوم وآلية العمل**
*   **التعريف البرمجي:** يقوم معامل **`min$`** بتحديث قيمة حقل رقمي إلى قيمة جديدة (محددة في الاستعلام)، **فقط ==إذا** كانت القيمة المحددة (**Specified Value**) **أصغر من** القيمة الحالية (**Current Value**) المخزنة== في الDocument .
*   **بصيغة أخرى للتوضيح:** سيتم التحديث إذا كانت القيمة الحالية في قاعدة البيانات "أكبر من" القيمة التي تحاول إدخالها. إذا كانت القيمة الحالية أصغر بالفعل من أو تساوي القيمة المحددة، فلن يقوم المعامل بأي تحديث .

### **التطبيق العملي: مجموعة الموظفين (`employees`)**
لتوضيح المفهوم، سنقوم بإجراء تجارب عملية على Document الموظف "John doe" الذي يبلغ عمره الحالي `32` عاماً.

**1. محاولة التحديث بقيمة أكبر (السيناريو الفاشل):**
*   **الهدف:** محاولة تغيير العمر (`age`) إلى `34` باستخدام `min$`.
*   **الكود البرمجي:**
```javascript
db.employees.updateOne(
    { name: "John doe" }, // تصفية الDocument
    { $min: { age: 34 } } // محاولة التحديث
)
```
*   **النتيجة المعمارية:** عند التنفيذ، وجد الخادم الDocument (`matchedCount: 1`) ولكنه لم يقم بتعديله (`modifiedCount: 0`). 
*   **السبب:** القيمة الحالية (32) **ليست أكبر من** القيمة المحددة (34). بعبارة أخرى، القيمة المحددة (34) ليست أصغر من القيمة الحالية، لذا تم تجاهل التحديث لأن الشرط لم يتحقق .

**2. محاولة التحديث بقيمة أصغر (السيناريو الناجح):**
*   **الهدف:** تغيير العمر (`age`) إلى `30` باستخدام `min$`.
*   **الكود البرمجي:**
```javascript
db.employees.updateOne(
    { name: "John doe" }, 
    { $min: { age: 30 } } 
)
```
*   **النتيجة المعمارية:** هذه المرة، أرجع الخادم (`modifiedCount: 1`).
*   **السبب:** القيمة المحددة (30) **أصغر من** القيمة الحالية (32). لذلك، تم تحديث حقل العمر بنجاح ليصبح `30` .

## **ثانياً: معامل الحد الأقصى (`max Operator$`)**

### **المفهوم وآلية العمل**
*   **التعريف البرمجي:** معامل **`max$`** هو العكس تماماً لمعامل `min$`. يقوم بتحديث قيمة الحقل الرقمي **فقط إذا** كانت القيمة المحددة (**Specified Value**) **أكبر من** القيمة الحالية (**Current Value**) للDocument.
*   **المنطق:** إذا كانت القيمة الحالية أصغر من القيمة الجديدة المحددة، سيتم التحديث. وإلا، سيتجاهل العملية .

### **التطبيق العملي: استكمال على Document الموظف**
بعد التجربة السابقة، أصبح العمر الحالي للموظف "John doe" هو `30`.

**1. محاولة التحديث بقيمة أكبر (السيناريو الناجح):**
*   **الهدف:** تغيير العمر إلى `34` باستخدام `$max`.
*   **الكود البرمجي:**
```javascript
db.employees.updateOne(
    { name: "John doe" }, 
    { $max: { age: 34 } } 
)
```
*   **النتيجة المعمارية:** تم التحديث بنجاح (`modifiedCount: 1`) لأن القيمة المحددة (34) **أكبر من** القيمة الحالية (30). أصبح العمر الآن `34`.

**2. محاولة التحديث بقيمة أصغر (السيناريو الفاشل):**
*   **الهدف:** محاولة تغيير العمر مرة أخرى إلى `32`.
*   **الكود البرمجي:**
```javascript
db.employees.updateOne(
    { name: "John doe" }, 
    { $max: { age: 32 } } 
)
```
*   **النتيجة المعمارية:** لن يتم التحديث (`modifiedCount: 0`) ولن يظهر أي خطأ برمجي (**Error**). تم تجاهل التحديث لأن القيمة المحددة (32) **ليست أكبر من** القيمة الحالية (34).

## **ثالثاً: معامل الضرب (`mul Operator$`)**

### **المفهوم وآلية العمل**
*   **التعريف البرمجي:** يُستخدم معامل **`mul$`** (وهو اختصار لـ **Multiply**) لضرب القيمة الحالية لحقل رقمي في رقم محدد، ثم تعيين الناتج كقيمة جديدة لهذا الحقل .
*   **الهدف المعماري:** مفيد جداً في العمليات الحسابية المباشرة داخل قاعدة البيانات دون الحاجة لاستخراج القيمة، حسابها في الواجهة الخلفية (**Backend**)، ثم إعادة إرسالها.

### **التطبيق العملي: مجموعة المنتجات (`products`)**
*   **الهدف:** سنستهدف  الDocument قبل الأخير في مجموعة المنتجات `products` باستخدام مُعرفه الفريد (`id_`). القيمة الحالية لحقل الخصم (`discount`) في هذا الDocument هي `10`. نريد مضاعفة هذه القيمة لتصبح `20` (عن طريق ضربها في 2).
*   **الكود البرمجي:**
```javascript
db.products.updateOne(
    { _id: ObjectId("...") }, // تصفية الDocument باستخدام المعرف
    { 
        $mul: { discount: 2 } // ضرب القيمة الحالية لحقل الخصم في 2
    }
)
```
*   **النتيجة المعمارية:** تم تنفيذ العملية بنجاح (`modifiedCount: 1`). عند الاستعلام عن الDocument، سيتغير حقل الخصم من `10` إلى `20` .

## **قواعد وملاحظات هامة (Important Notes & Best Practices)**
1.  **دوال التحديث المتوافقة:** استخدم المحاضر دالة `updateOne` في هذه الأمثلة لتبسيط الشرح، ولكن جميع هذه المعاملات (`min`, `$max`, `$mul$`) تعمل بكفاءة تامة دون أي قيود مع دالة التحديث الجماعي **`updateMany`** أيضاً.
2.  **نوع البيانات:** تذكر دائماً أن هذه المعاملات مصممة للعمل مع **الحقول الرقمية (Numeric Fields)** فقط ولا تُستخدم مع النصوص أو المصفوفات.
3.  **الخطوات القادمة:** المحاضرة القادمة ستتناول كيفية حذف حقل بالكامل من الDocument (**Remove a field**)، وكيفية إعادة تسمية حقل موجود (**Rename a field**).
