
## **مقدمة: عمليات التحديث في MongoDB**
بعد أن تعرفنا في الدروس السابقة على كيفية إنشاء (**Create**) وقراءة (**Read**) المستندات، ننتقل الآن إلى وظيفة أساسية أخرى وهي كيفية تحديث البيانات الحالية (**Updating Documents**) من خلال واجهة سطر الأوامر (**Mongo Shell**). توفر **MongoDB** دوال مختلفة لتحديث Document واحد بمفرده، أو تحديث مجموعة من الDocument دفعة واحدة.

---

## **استرجاع البيانات قبل التحديث (Fetching before Updating)**
قبل القيام بعملية التحديث، من الشائع أن نقوم بجلب الDocument للتأكد من بياناته. هنا لازم نعرف الفرق بين استخدام دالتي `find` و `findOne` عند البحث باستخدام حقل المعرف الفريد `id_`:
*   **باستخدام `find`:** إذا بحثنا عن Document يمتلك `id: 100_`، ستقوم الدالة بإرجاع النتيجة داخل مصفوفة (**Array**) تحتوي على هذا الDocument الوحيد .
*   **باستخدام `findOne`:** نظراً لأننا متأكدون من أن حقل `id_` فريد ولن يتكرر، يفضل استخدام هذه الدالة لأنها لا تُرجع مصفوفة، بل تُرجع الكائن (**Object / Document**) مباشرة وبشكل مباشر.
*   **بيانات الDocument الافتراضي للمثال:** الDocument الذي سيتم تطبيق المثال عليه يمتلك البيانات التالية:
* `_id: 100`، `name: test`، `age: 32`، `gender: female`.

---

## **تحديث مستند واحد (Updating a Single Document)**

لتحديث مستند واحد فقط داخل الـ **Collection**، نستخدم الدالة **`updateOne`**. 

### **هيكلة الدالة `updateOne` والمعاملات الخاصة بها (Arguments)**
تستقبل هذه الدالة معاملين أساسيين (Two Arguments):
1.  **كائن التصفية (==Filter Object==):** المعامل الأول هو الكائن الذي نحدد فيه شروط البحث لإيجاد المستند المراد تحديثه (مثلاً تحديد المستند ذو `_id: 100`).
2.  **مستند التحديث (==Updating Document==):** المعامل الثاني هو الكائن الذي يحتوي على القيم الجديدة التي نريد تعيينها. هنا **يجب** استخدام المعامل **`set$`**.

### **المعامل `$set` (The `$set` Operator)**
*   يُستخدم لتحديد الحقول (**Fields**) التي نريد تعيين قيم جديدة لها.
*   يمكنك تحديث حقل واحد فقط، أو تحديث حقول متعددة (**Multiple Fields**) في نفس الوقت عن طريق الفصل بينها بفاصلة (**Comma**) داخل كائن الـ `set$`.

**مثال برمجي (تحديث العمر والجنس):**
نريد تحديث عمر المستخدم إلى 50، وتغيير الجنس إلى "male" .
```javascript
db.users.updateOne(
    { _id: 100 }, // 1. Filter Object
    { $set: { age: 50, gender: "male" } } // 2. Updating Document with $set
)
```

### **تحليل استجابة الخادم (Server Response Analysis)**
عند تنفيذ أمر التحديث، يرسل الخادم استجابة تحتوي على معلومات هامة:
*  `‏` **`acknowledged: true`**: تعني أن العملية قُبلت ونُفذت بنجاح.
*  `‏` **`insertedId: null`**: لأننا قمنا بالتحديث وليس الإدراج الجديد.
* `‏`  **`matchedCount: 1`**: تعني أنه تم العثور على Document واحد يطابق شروط الفلتر.
* `‏`  **`modifiedCount: 1`**: تعني أنه تم تعديل Document واحد بالفعل.
* `‏`  **`upsertedCount: 0`**: (مفهوم الـ **Upsert** سيتم شرحه في محاضرة قادمة).

---

## **سلوكيات هامة لدالة `updateOne`**

### **1. ماذا يحدث إذا طابق الفلتر عدة Documents؟ (Multiple Matches)**
إذا قمنا بتمرير فلتر يطابق عدة Documents (مثلاً البحث عن كل من يحمل اسم "John")، فإن دالة `updateOne` **لن تقوم بتحديث كل المستندات المطابقة**. بل ستقوم بتحديث **المستند الأول فقط (==First matching document==)** الذي تجده في الـ **Collection** .

**مثال برمجي:**
لدينا مستندان يحملان اسم "John" (الأول ذكر، والثاني غير معروف). إذا حاولنا تغيير الجنس إلى "female":
```javascript
db.users.updateOne(
    { name: "John" },
    { $set: { gender: "female" } }
)
```
*   **النتيجة:** سيتغير جنس الDocument الأول فقط لـ "female"، بينما سيظل المستند الثاني كما هو ولن يتأثر .

### **2. ماذا يحدث إذا حاولنا تحديث حقل غير موجود؟ (Updating a Non-existent Field)**
إذا حاولت استخدام `set$` لتحديث حقل ليس له وجود أصلاً في الDocument، ==ستقوم **MongoDB** **بإنشاء هذا الحقل== أولاً** داخل الDocument، ثم تسند إليه القيمة التي حددتها .

**مثال برمجي:**
لدينا مستند باسم "Steve" لا يمتلك حقل `gender`. سنقوم بتحديثه:
```javascript
db.users.updateOne(
    { _id: ObjectId("...") }, // الفلتر باستخدام المعرف
    { $set: { gender: "male" } }
)
```
*   **النتيجة:** سيتم إضافة حقل `gender: "male"` إلى هذا المستند بشكل طبيعي جداً .

---

## **تحديث مستندات متعددة دفعة واحدة (Updating Multiple Documents)**

إذا أردنا تحديث جميع الDocument التي تطابق شرطاً معيناً (وليس الDocument الأول فقط)، يجب أن نستخدم دالة **`updateMany`** .

*   تأخذ هذه الدالة نفس المعاملات تماماً مثل الدالة السابقة: الأول (الفلتر)، والثاني (كائن التحديث باستخدام `$set`).

**مثال برمجي:**
تحديث حقل الجنس ليصبح "male" لـ **جميع** المستخدمين الذين يحملون اسم "Steve" .
```javascript
db.users.updateMany(
    { name: "Steve" }, 
    { $set: { gender: "male" } }
)
```

### **فهم العلاقة بين (matchedCount) و (modifiedCount)**
في المثال السابق، كان هناك مستندان باسم "Steve". الأول جنسه غير معروف، والثاني جنسه "male" مسبقاً. 
عند تنفيذ الكود، ستكون الاستجابة:
* `‏`   **`matchedCount: 2`**: الخادم وجد مستندين باسم "Steve".
* `‏`  **`modifiedCount: 1`**: تم تعديل مستند واحد فقط! (لأن المستند الثاني كان يمتلك القيمة "male" بالفعل، فلم تكن هناك حاجة لتعديله).

(ملاحظة: تماماً مثل الدالة السابقة، إذا استخدمت `updateMany` لتحديث حقل غير موجود، مثل حقل المدينة `city: "London"` لجميع من اسمهم "Steve"، سيتم إنشاء هذا الحقل الجديد وإضافته لجميع المستندات المطابقة* .

---

## **الخطأ الناتج عن نسيان المُعامل الافتراضي (Missing `$set` Error)**

 ماذا لو استخدمنا `updateMany` ولكننا نسينا كتابة المعامل `set$` ومررنا القيمة مباشرة؟

```javascript
// كود خاطئ عمداً
db.users.updateMany(
    { name: "Steve" },
    { country: "UK" } // خطأ: تم تجاهل $set
)
```
*   **النتيجة:** سيتم رفض العملية وسيرجع الخادم خطأ برمجياً من نوع **Mongo invalid argument error**.
*   **السبب:** تخبرك رسالة الخطأ أن دالة التحديث تتطلب عوامل ذرية (**Atomic operators**) مثل `$set` لكي تعمل بشكل صحيح.

## **استبدال مستند بالكامل (Replacing an Entire Document)**

في بعض الأحيان، لا نريد فقط تحديث حقل أو حقلين، بل نريد استبدال الDocument بالكامل (إزالة كل الحقول القديمة ووضع حقول جديدة)، مع الاحتفاظ بنفس المُعرف الفريد `id_`. لتحقيق ذلك، نستخدم دالة **`replaceOne`** .

*   تستبدل هذه الدالة أول مستند يطابق الفلتر، وتضع مكانه الكائن الجديد بالكامل.

**مثال برمجي:**
نريد استبدال مستند "Steve" (الذي كان يحتوي على العمر والجنس) بمستند جديد لا يحتوي سوى على الاسم، المدينة، والدولة:
```javascript
db.users.replaceOne(
    { name: "Steve" }, // 1. كائن التصفية
    { name: "Steve", city: "Delhi", country: "India" } // 2. المستند الجديد بالكامل
)
```
*   **النتيجة:** سيتم مسح الحقول القديمة (`age` و `gender`) تماماً. وسيصبح المستند يحتوي فقط على الحقول الجديدة، ولكنه سيظل محتفظاً بنفس قيمة `_id` القديمة دون أي تغيير.

---

## **ملخص الدوال (Summary of Methods)**
* `‏`  **`updateOne`**: تُستخدم لتحديث حقول معينة في **مستند واحد فقط** (أول مستند يطابق الفلتر).
* `‏`  **`updateMany`**: تُستخدم لتحديث حقول معينة في **جميع الDocuments** التي تطابق الفلتر .
*  `‏` **`replaceOne`**: تُستخدم **لاستبدال** مستند كامل بآخر جديد (مع الحفاظ على `id_`) بدلاً من تحديث الحقول بشكل فردي.
