
## **مقدمة: ما هي معاملات المقارنة (Comparison Operators)؟**
تُستخدم معاملات المقارنة في **MongoDB** لمقارنة القيم داخل الاستعلامات (**Queries**). 
*   **الوظيفة الأساسية:** تتيح لك هذه المعاملات تصفية وفلترة المستندات (**Filter Documents**) بناءً على شروط محددة ومعايير دقيقة.
*   **التوثيق الرسمي (Official Documentation):** يمكن الوصول لقائمة هذه المعاملات وتفاصيلها عبر موقع **MongoDB** الرسمي من خلال المسار التالي: (Resources -> Server documentation -> References -> Operators -> Query and projection operators). حيث يوفر التوثيق شرحاً مفصلاً وأمثلة لكل معامل .

## **أولاً: معاملات المساواة وعدم المساواة**

### **1. التطابق التام (eq / Equal$)**
*   **الوظيفة:** يُستخدم هذا المعامل للبحث عن الDocumentات التي تتطابق فيها قيمة الحقل تماماً مع القيمة المحددة.
*   **المثال العملي:** فلترة جميع المنتجات التي يبلغ تقييمها (`ratings`) القيمة `8.2` بالضبط.
*   **طريقة الكتابة المختصرة (Shorthand):** يمكن كتابة الاستعلام بدون المعامل للحصول على نفس النتيجة:
```javascript
db.products.find({ ratings: 8.2 })
```
*   **طريقة الكتابة باستخدام المعامل:**
```javascript
db.products.find({ ratings: { $eq: 8.2 } })
```
(النتيجة: أرجع الاستعلام Documentين اثنين يمتلكان التقييم 8.2).
### **ملاحظة برمجية: دالة العد (`count`)**
أثناء الاستعلام، يمكننا استخدام دالة ==`()count.`== وإلحاقها بالاستعلام لمعرفة عدد الDocumentات التي طابقت الشرط داخل مجموعة النتائج (**Result Set**) بدلاً من طباعة الDocumentات بأكملها.

### **2. عدم التطابق (ne / Not Equal$ )**
*   **الوظيفة:** عكس معامل `eq$`. يُستخدم لاسترجاع كافة الDocumentات التي **لا تتساوى** قيمة حقلها مع القيمة المحددة.
*   **المثال العملي:** جلب جميع المنتجات التي لا يساوي تقييمها `8.2`.
```javascript
db.products.find({ ratings: { $ne: 8.2 } }).count()
```
(النتيجة: أرجع الاستعلام العدد 16. بما أن المجموع الكلي هو 18 Documentاً، وهناك Documentان بتقييم 8.2، فإن الباقي هو 16 Document ).

## **ثانياً: معاملات المقارنة الكمية والعددية**

### **1. أكبر من (gt / Greater Than$ )**
*   **الوظيفة:** فلترة الDocumentات التي تكون قيمة حقلها **أكبر قطعيّاً** من القيمة المحددة.
*   **المثال العملي:** البحث عن المنتجات التي تقييمها أعلى من `8`.
```javascript
db.products.find({ ratings: { $gt: 8 } })
```

### **2. أصغر من (lt / Less Than$ )**
*   **الوظيفة:** فلترة الDocumentات التي تكون قيمة حقلها **أصغر قطعيّاً** من القيمة المحددة.
*   **المثال العملي:** البحث عن المنتجات التي يقل تقييمها عن `8`.
```javascript
db.products.find({ ratings: { $lt: 8 } })
```

### **3. أصغر من أو يساوي (lte / Less Than or Equal To$ )**
*   **الوظيفة:** إرجاع الDocumentات التي تكون قيمة حقلها أصغر من، أو تتطابق تماماً مع القيمة المحددة.
*   **المثال العملي:** البحث عن المنتجات التي تقييمها `7.9` أو أقل.
```javascript
db.products.find({ ratings: { $lte: 7.9 } })
```
(النتيجة: جلب الاستعلام 3 Documentات تطابق هذا الشرط)*.

### **4. أكبر من أو يساوي (]gte / Greater Than or Equal To$)**
*   **الوظيفة:** إرجاع الDocumentات التي تكون قيمة حقلها أكبر من، أو تتطابق تماماً مع القيمة المحددة .
*   **المثال العملي:** البحث عن المنتجات التي تقييمها `9.2` أو أكثر.
```javascript
db.products.find({ ratings: { $gte: 9.2 } })
```

## **ثالثاً: معاملات المقارنة داخل المصفوفات (Array Comparison)**
تحتوي Documentات المنتجات في هذا المثال على حقل `category` (الفئة)، وهو عبارة عن مصفوفة (**Array**) تضم قيماً نصية بالحروف الصغيرة (مثل "electronics", "gaming", "mobile", "laptop") .

### **1. معامل التضمين (in / In Operator$)**
*   **الوظيفة:** يُستخدم للبحث عما إذا كان الحقل (خاصة المصفوفات) يحتوي على **أي قيمة** من ضمن قائمة أو مصفوفة من القيم التي تحددها .
*   **المثال العملي:** نريد جلب كافة المنتجات التي تنتمي لفئة الهواتف ("mobile") **أو** فئة الحواسيب المحمولة ("laptop").
*   **القاعدة البرمجية:** يجب أن نمرر مصفوفة (**Array**) كقيمة لمعامل `$in` تحتوي على العناصر التي نبحث عنها.
```javascript
db.products.find({ category: { $in: ["mobile", "laptop"] } })
```
*(النتيجة: أرجع الاستعلام 4 Documentات تحتوي مصفوفة `category` الخاصة بها إما على "mobile" أو "laptop" أو كليهما)* [9، 10].

### **2. معامل الاستبعاد (nin / Not In Operator$)**
*   **الوظيفة:** هو العكس تماماً لمعامل `$in`. يقوم بفلترة الDocumentات واستبعاد أي Document يحتوي حقله على أي من القيم المحددة في المصفوفة.
*   **المثال العملي:** جلب جميع المنتجات التي **لا تنتمي** لا لفئة الهواتف ولا لفئة الحواسيب المحمولة.
```javascript
db.products.find({ category: { $nin: ["mobile", "laptop"] } })
```
(النتيجة: أرجع الاستعلام 14 Document لا تحتوي مصفوفة الفئات الخاصة بها على أي من الكلمتين المحددة)*.

---

**خلاصة:**
معاملات المقارنة (**Comparison Operators**) هي أدوات جوهرية داخل استعلامات **MongoDB** لبناء شروط دقيقة. من خلال دمج هذه المعاملات مع كائن التصفية (**Filter Object**)، يستطيع مهندس البيانات استخراج مجموعات محددة جداً من البيانات بكفاءة وسرعة، سواء كانت البيانات أرقاماً دقيقة أو نصوصاً داخل مصفوفات
