## الوحدات المدمجة ووحدة المسارات (Built-in Modules & Path Module)

### 1. المفهوم الأساسي: الوحدات المدمجة (Built-in Modules)

**التعريف:** الوحدات المدمجة (**Built-in Modules**) هي عبارة عن أكواد برمجية توفرها بيئة Node.js بشكل جاهز ومدمج (Out of the box) لمساعدة المطورين في بناء التطبيقات دون الحاجة لكتابة هذه الأكواد من الصفر.

---

### 2. وحدة المسارات (Path Module)

**التعريف:** وحدة المسارات (**Path Module**) هي أول وحدة مدمجة ندرسها، وتوفر مجموعة من الأدوات والوظائف (Utilities) للعمل والتعامل مع الملفات ومسارات المجلدات (Directory paths).

**الفكرة الأساسية:** تحتوي هذه الوحدة على حوالي 14 خاصية وطريقة (Properties and methods) مختلفة، ولكن التركيز العملي ينصب على 7 وظائف رئيسية تُستخدم بكثرة في بناء التطبيقات الحقيقية.

---

### 3. خطوات استيراد الوحدات المدمجة وبروتوكول Node

لاستخدام أي وحدة مدمجة مثل `path`، يجب أولاً استيرادها إلى الملف الرئيسي (مثل `index.js`).

**الخطوات:** **Step 1:** نستخدم دالة `require` المعتادة في Node.js. **Step 2:** نُمرر اسم الوحدة المدمجة مسبوقاً ببروتوكول `:node`.

```javascript
// استيراد وحدة path
const path = require('node:path');
```

_شرح الكود:_

-`‏` `path`: هو اسم الوحدة المدمجة.
-`‏` `:node`: بادئة (Prefix) تشير إلى أن هذه الوحدة مدمجة في البيئة.
- **ملاحظة:** لا نستخدم نقطة وشرطة مائلة `/.` في البداية كما نفعل مع الLocal module.

> `‏` **Important Note** **لماذا نستخدم البادئة `:node`؟** بيئة Node.js ذكية بما يكفي لمعرفة أن الوحدة مدمجة حتى لو كتبنا `require('path')` بدون البادئة. ومع ذلك، **يُنصح بشدة (Highly recommended)** باستخدام بادئة `:node` للأسباب الثلاثة التالية:
> 1. تجعل من الواضح تماماً (وخاصة للمبتدئين) أن هذا الاستيراد هو لوحدة مدمجة في Node.js وليس حزمة خارجية.
> 2. تجعل معرّف الاستيراد (Import identifier) عبارة عن عنوان URL مطلق صالح (Valid absolute URL).
> 3. تتجنب حدوث أي تعارضات (Avoids conflicts) مع أي وحدات مدمجة قد تُضاف إلى Node.js في المستقبل.

---

### 4. مراجعة: متغيرات التيسير (Convenience Variables)

قبل التعمق في دوال `path`، يجب استحضار متغيرين متاحين بشكل جاهز في كل وحدة، وسنستخدمهما في الأمثلة:

-`‏` **`filename__`**: سلسلة نصية (String) تمثل المسار الكامل للملف الحالي (Full path to the file).
-`‏` **`dirname__`**: سلسلة نصية (String) تمثل المسار الكامل للمجلد الذي يحتوي على الملف (Full path to the folder).

---

### 5. وظائف وحدة المسارات السبع (The 7 Path Methods)

بعد استيراد الوحدة، يمكننا الوصول إلى الوظائف التالية:

#### 1. دالة `()path.basename`

- **التعريف:** دالة تقوم بإرجاع الجزء الأخير (Last portion) من المسار.
- **مثال تطبيقي:**
    
    ```javascript
    console.log(path.basename(__filename)); // يُرجع: index.js
    console.log(path.basename(__dirname));  // يُرجع: node.js (اسم المجلد)
    ```
    
    (الشرح: استخرجت الدالة اسم الملف الدقيق من مسار الملف، واسم المجلد الأخير من مسار المجلد).
#### 2. دالة `path.extname()`

- **التعريف:** دالة تُرجع امتداد الملف (Extension) من المسار.
- **مثال تطبيقي:**
    
    ```javascript
    console.log(path.extname(__filename)); // يُرجع: .js
    console.log(path.extname(__dirname));  // يُرجع: '' (سلسلة نصية فارغة)
    ```
    
    _(الشرح: المجلد ليس له امتداد لأنه لا يحتوي على نقطة `.` في مساره، لذا أرجعت الدالة سلسلة فارغة)._

#### 3. دالة `()path.parse`

- **التعريف:** دالة تحلل المسار وتُرجع "كائناً" (Object) تمثل خصائصه العناصر المهمة للمسار.
- **الخصائص المُرجعة:** الجذر (`root`)، المجلد (`dir`)، الجزء الأخير (`base`)، الامتداد (`ext`)، واسم الملف (`name`).
- **مثال تطبيقي:**
    
    ```javascript
    console.log(path.parse(__filename));
    // سيطبع كائناً يحتوي على الخصائص المذكورة أعلاه. يمكن الوصول لأي منها عبر التنقيط (Dot notation).
    ```
    

#### 4. دالة `()path.format`

- **التعريف:** هي عكس دالة `parse` تماماً. تأخذ كائناً (Object) وتُرجع سلسلة نصية تمثل المسار (Path string).
- **مثال تطبيقي:**

    ```javascript
    // تمرير الكائن الناتج من parse إلى دالة format
    console.log(path.format(path.parse(__filename)));
    // يُرجع: المسار الأصلي الكامل للملف
    ```
   

#### 5. دالة `()path.isAbsolute`

- **التعريف:** دالة للتحقق مما إذا كان المسار المعطى هو "مسار مطلق" (Absolute path) أم لا، وتُرجع قيمة منطقية (Boolean).
- **مثال تطبيقي:**
    
    ```javascript
    console.log(path.isAbsolute(__filename)); // يُرجع: true (لأنه مسار مطلق)
    console.log(path.isAbsolute('./data.json')); // يُرجع: false (لأن المسار النسبي يبدأ بـ ./)
    ```
    

#### 6. دالة `()path.join`

- **التعريف:** دالة تستقبل سلسلة نصية واحدة أو أكثر (One or more strings)، وتقوم بدمجها معاً (Joins them) باستخدام الفاصل الخاص بنظام التشغيل كـ محدد (Platform specific separator as a delimiter).
- **ميزة الفاصل النظامي:** الفاصل يكون شرطة مائلة عادية `/` في نظام Mac، وشرطة مائلة عكسية `\` في نظام Windows.
- **ميزة التسوية (Normalization):** تقوم الدالة أيضاً بتسوية المسار الناتج وإصلاح أي كتابة غير منطقية.
- **أمثلة متدرجة لفهم الآلية:**
    
    ```javascript
    // 1. الدمج البسيط
    console.log(path.join('folder1', 'folder2', 'index.html'));
    // النتيجة: folder1/folder2/index.html
    
    // 2. الدمج مع شرطة مائلة في البداية
    console.log(path.join('/folder1', 'folder2', 'index.html'));
    // النتيجة: /folder1/folder2/index.html (تُحفظ الشرطة في البداية)
    
    // 3. التسوية (Normalization)
    console.log(path.join('/folder1', '//folder2', 'index.html'));
    // النتيجة: /folder1/folder2/index.html (تم دمج الشرطتين // إلى شرطة واحدة /)
    
    // 4. القفز للأعلى (Jumping up a folder)
    console.log(path.join('/folder1', 'folder2', '../index.html'));
    // النتيجة: /folder1/index.html (الـ ../ تعني الصعود مجلداً واحداً للأعلى، فتجاهل folder2)
    
    // 5. الدمج مع متغيرات التيسير
    console.log(path.join(__dirname, 'data.json'));
    // النتيجة: مسار مطلق كامل ينتهي بـ data.json
    ```

> `‏` **Important Note** ينصح المحاضر بتجنب استخدام `../` داخل `path.join` قدر الإمكان لأنها تجعل الكود مُربكاً وصعب الفهم (Confusing).


#### 7. دالة `()path.resolve`

- **التعريف:** دالة تقوم بتحليل سلسلة من المسارات أو أجزاء المسار وتحويلها دائماً إلى **مسار مطلق (Absolute path)**.
- **طريقة العمل (دقيقة وتحتاج تركيز):** تبدأ الدالة بقراءة الparameters من اليمين إلى اليسار، وتستمر في الدمج حتى تُشكل مساراً مطلقاً. المسار الناتج يعتمد كلياً على الparameters المُمررة.
- **أمثلة توضيحية لآلية العمل:**
    
    ```javascript
    // 1. عدم وجود شرطة مائلة (No forward slash)
    console.log(path.resolve('folder1', 'folder2', 'index.html'));
    // النتيجة: يضيف المسار المطلق للمجلد الحالي، ثم يدمج الباقي. (مثال: /Users/.../folder1/folder2/index.html)
    
    // 2. وجود شرطة مائلة في البداية (Forward slash at the start)
    console.log(path.resolve('/folder1', 'folder2', 'index.html'));
    // النتيجة: يعتبر /folder1 هي الجذر المطلق. (/folder1/folder2/index.html)
    
    // 3. وجود شرطة مائلة في المنتصف
    console.log(path.resolve('folder1', '//folder2', 'index.html'));
    // النتيجة: يعتبر //folder2 هي الجذر المطلق، ويتجاهل ما قبلها تماماً. (/folder2/index.html)
    
    // 4. التجاهل والقفز للأعلى
    console.log(path.resolve('folder1', '//folder2', '../index.html'));
    // النتيجة: يعتبر //folder2 هي الجذر، ثم يصعد مجلداً واحداً بسبب ../ (/index.html)
    
    // 5. استخدام مسار مطلق جاهز
    console.log(path.resolve(__dirname, 'data.json'));
    // النتيجة: مسار مطلق كامل (لأن __dirname أصلًا مسار مطلق).
    ```

### 6. جدول مقارنة: `join` مقابل `resolve`

|                               `path.resolve()`                               |                       `path.join()`                       |            Feature            |
| :--------------------------------------------------------------------------: | :-------------------------------------------------------: | :---------------------------: |
|    إنشاء **مسار مطلق (Absolute Path)** من الأجزاء المعطاة مهما كلف الأمر.    | دمج أجزاء المسار بشكل نصي وإصلاح الفواصل (Normalization). |       **الهدف الأساسي**       |
|         يعتبرها نقطة الأصل (Root) **ويتجاهل** أي مسارات سُجلت قبلها.         |       يقوم بتسويتها ويدمجها بشكل طبيعي مع ما قبلها.       | **التعامل مع `/` في المنتصف** |
| يُضيف مسار المجلد الحالي (Current working directory) إجبارياً ليجعله مطلقاً. |       يُرجع مساراً نسبياً إذا كانت المدخلات نسبية.        |    **عدم وجود مسار مطلق**     |
